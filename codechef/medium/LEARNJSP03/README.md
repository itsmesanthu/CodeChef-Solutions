## Problem

### Printing text

Listen

In the last problem, we saw how to print a number (using `console.log() method`).

Now let's see how to output some text.
There is only one difference. All textual content should start and end with double quotes or single quotes.
For eg -

```
console.log("I love JavaScript");

```

### Task
- Replace the _ (underscores) in the editor with the text I love JavaScript and Submit.

## Solution

**Language:** JavaScript  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-10-29T15:24:14.145Z  

```js
// Replace __  (underscores) with "I love JavaScript"
let txt='I love JavaScript';
console.log(txt);

```
