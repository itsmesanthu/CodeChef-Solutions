## Problem

### If Statement

Listen

The  **else**  statement is optional.

Here is an example

```
var grade = 95;
if(grade >= 90){
    console.log("You got an A");
}

// Output:
// You got an A

```

In the above program, if the condition is True, then the  **`console`**  statement is executed.
