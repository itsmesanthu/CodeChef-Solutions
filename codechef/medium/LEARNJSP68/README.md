## Problem

### Multiple Choice Question

What will be the output of this code?

```

var b = -10;

if (a >= b) {
   console.log("a is greater or equal to b.");
}
if (a === 0) {
   console.log("a is 0.");
}
if (a <= 5) {
   console.log("a is not more than 5.");
}
console.log("Program ends");

```
