## Problem

### Basic Operations with Series

Series support various mathematical and statistical operations that you saw as part of NumPy arrays.

Run the code given in the IDE to see some of the mathematical and statistical operations in action.

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-06T11:51:30.038Z  

```py
import pandas as pd

s = pd.Series([1, 2, 3, 3, 5])

print(s)
print(s + 2)
print(s * 2)
print(s.mean())
print(s.median())
print(s.std())
```
