## Problem

Write a program to output the square of * (stars) of size 4 (check the output below).

```
  
  
  
   

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-04T12:21:59.464Z  

```py
n=4
for i in range(0,n):
    for j in range(0,n):
        print("*",end="")
    print()
```
