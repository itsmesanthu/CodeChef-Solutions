## Problem

### Print Pattern

Write a program to output the square of * (stars) of size 4 (check the output below).

```
  
  
  
   

```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-17T18:00:45.596Z  

```py
for i in range(4):
    for j in range(4):
        print("*",end="")
    print()

```
