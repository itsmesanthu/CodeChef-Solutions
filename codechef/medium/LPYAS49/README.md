## Problem

Write a program that takes the radius of a circle as input and prints its area

 **formula to calculate area of circle: `3.14 *radius* radius`** 

### Sample 1:
Input
Output

```
5
```

```
78.5
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-24T15:40:25.361Z  

```py
# cook your dish here
r=int(input())
print(3.14*r*r)
```
