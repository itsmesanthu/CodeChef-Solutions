## Problem

Which lines of code will output the sum of 7 and 19?

 **Hint: There are two correct answers.**

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-04T12:22:08.146Z  

```py
n=4
for i in range(0,n):
    for j in range(0,n):
        print("*",end="")
    print()
```
