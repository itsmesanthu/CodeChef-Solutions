## Problem

### Multiple Choice Question

What will be the output of this code?

```
a = 0
b = -10

if a >= b:
   print("a is greater or equal to b.")
if a == 0:
   print("a is 0.")
if a <= 5:
   print("a is not more than 5.")
print("Program ends")

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-25T13:46:42.183Z  

```cpp
score = int(input())
if score==100:
    print("Perfect score")
elif score>=80:
    print("Almost perfect score")
else:
    print("Nice try")
```
