![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Write a program that takes 3 string inputs from the user: a `name`, a `verb`, and a `place`. Use these inputs to construct a sentence in the following format:

`"<name> is <verb> in the <place>"`

### Sample 1:
Input
Output

```
Alice dancing park
```

```
Alice is dancing in the park
```

### Sample 2:
Input
Output

```
Rohan chilling club
```

```
Rohan is chilling in the club
```

## Solution

**Language:** Python  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-09-24T15:38:24.803Z  

```py
# Update the code below this li
n,v,p=input().split()
print(f"{n} is {v} in the {p}")
```
